# API reference

The reference of the public types of every package, made from the XML documentation of the code.

| Namespace | Package | What is in it |
|---|---|---|
| `ParquetNeo` | `ParquetNeo`, `ParquetNeo.Enums` | The file reader and writer, row groups and columns, options, filters, the enumerations of the format |
| `ParquetNeo.Schema`, `ParquetNeo.Metadata` | `ParquetNeo` | The schema tree and the structures of the footer and of the page index |
| `ParquetNeo.Data` | `ParquetNeo` | The ADO.NET reader and writer |
| `ParquetNeo.Serialization` | `ParquetNeo.Serialization` | `ParquetSerializer` and its options |
| `ParquetNeo.DataModel` | `ParquetNeo.Serialization` | The attributes that adjust the mapping, and `[ParquetSerializable]` |
| `ParquetNeo.Linq` | `ParquetNeo.Linq` | `ParquetDataset` |
